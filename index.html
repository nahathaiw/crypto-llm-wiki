Crypto Basics LLM Wiki

I built an LLM-maintained wiki about blockchain and cryptocurrency for beginners, using a "discuss first, then generate" (先討論、後生成) process. It has 10 concept pages from 8 ingested sources. Then I had the AI build a teaching slide deck using only the wiki as its knowledge source. Every slide links back to the wiki page it came from.

Teaching slides →16 slides, "Crypto from zero". Use ← → to move, C for contents, F for fullscreen. The LLM Wiki →10 pages. Every claim has a source tag that links to its raw note. Source files →raw/, wiki/*.md, AGENTS.md, check scripts and run logs.

Loop / graph design

flowchart TD
  A[Discuss: topic, audience, pages, sources] --> B[Fetch source]
  B --> C{Ingest check: loaded? date? fact or opinion? conflicts?}
  C -- blocked --> B2[Replace source] --> B
  C -- ok, flag bad claims --> D[Write raw/S#.md]
  D -->|repeat per source| B
  D --> E[Generate / update wiki pages with source tags]
  E --> F{Lint script}
  F -- fail --> E
  F -- pass --> G{Grounding check: claim vs raw note}
  G -- fail --> E
  G -- pass --> H[Query wiki → slide outline]
  H --> I[Generate HTML slides]
  I --> J{Slide check: traceability + claim review}
  J -- fact missing from wiki --> E
  J -- wording / tag issue --> I
  J -- pass --> K{Render check: desktop + phone}
  K -- layout bug --> I
  K -- pass --> L[Publish]

Full explanation (which steps repeat, where the checks are, and why): loop-design.md

Real runs and check records
